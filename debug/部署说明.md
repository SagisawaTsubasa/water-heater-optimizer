# water-heater-optimizer v0.5.1 部署说明

> 真机验证/发布前置交付文档。本文所有操作归用户；施工侧只交付代码与本说明。
>
> 版本口径：v0.5.1（manifest.json）；最小 HA 版本 2024.11.0（hacs.json）；开发对齐 HA 26.1.3。

## 仓现状（2026-11-16 实况）

- git remote：`origin = https://github.com/SagisawaTsubasa/water-heater-optimizer.git`（已配置，远端仓已存在）。
- 本地 `main` 领先 `origin/main` 若干 commit（v2 施工 + 0.5.0/0.5.1 两批），均未推送；推前以 `git status` / `git log origin/main..main` 实数为准。
- 远端已有 v0.4.0 Release；**v0.5.1 尚无 Release**——HACS 默认按 Release 拉取版本，没发 Release 前走 HACS 装不到 0.5.1（0.5.0 同）。

## 链路 A：HACS 正式链路（推荐）

1. **推送**：`git push origin main`（本地领先 origin/main 的全部 commit 一次推齐，数量以 `git log origin/main..main --oneline | wc -l` 为准；push 归用户）。
2. **建 Release**（GitHub 仓页 → Releases → Draft a new release）：
   - tag：`v0.5.1`（打在 main 最新 commit 上）
   - 标题：`v0.5.1`
   - 正文可直接引用 README「更新日志」0.5.1 段（含用户可见行为变化：重载/重启后总闸 on 会追平一次下发）。
3. **HA 侧 HACS 添加自定义仓库**：HACS → ⋮ 菜单 → 自定义仓库 → 仓库填 `https://github.com/SagisawaTsubasa/water-heater-optimizer`，类别选 **集成（Integration）**。
4. HACS 中安装 **Water Heater Optimizer** → 按提示重启 Home Assistant。
5. 已装旧版（0.3.0/0.4.0/0.5.0）的：HACS 里更新到 0.5.1 后重启 HA。0.3.0→0.4.0 跨版需按《条目重配指引.md》重配条目；升到 0.5.1 无条目变更，重启即可（自动调节开启的条目重启后自动追平一次下发，见 README 更新日志 0.5.1 段）。

## 链路 B：手动安装（不发 Release 时）

1. 把本仓 `custom_components/water_heater_optimizer/` 整目录复制到 HA 配置目录 `custom_components/` 下，覆盖旧版。
2. **手动删除旧版残留文件**（覆盖复制不会删除旧目录里已砍除的文件）：
   - 从 0.3.0 升级：删 `services.yaml`（0.4.0 已删，take_snapshot 服务随触发器体系整体移除，避免留下描述不存在服务的 YAML）；
   - 从 0.4.0 升级：删 `web.py` 与 `static/` 子目录（0.5.0 已删文羽面板页，manifest 不再依赖 `http`——见 README「手动安装」第 3 步与更新日志 0.5.0 段）。
3. 重启 Home Assistant。
4. 0.3.0 升级路径需按《条目重配指引.md》重配条目；0.4.0/0.5.0 升级无需重配。

## 部署后自检（一步）

重启完成后，日志（设置 → 系统 → 日志，或记录器 `custom_components.water_heater_optimizer`）应无 ERROR；条目重配完成前推荐温度实体可能显示旧值/unknown，属预期，见《条目重配指引.md》。
