# water-heater-optimizer v0.4.0 部署说明

> 步骤 8 真机验证的前置交付文档。本文所有操作归用户；施工侧只交付代码与本说明。
>
> 版本口径：v0.4.0（manifest.json）；最小 HA 版本 2024.11.0（hacs.json）；开发对齐 HA 26.1.3。

## 仓现状（2026-11-15 实况）

- git remote：`origin = https://github.com/SagisawaTsubasa/water-heater-optimizer.git`（已配置，远端仓已存在）。
- 本地 `main` 领先 `origin/main` **6 个 commit**（v2 全部施工：核心重构 → 平台配置 → 测试基线 → 壳接入 → R1-fix → AOCI 索引），均未推送。
- **远端尚无 v0.4.0 Release**——HACS 默认按 Release 拉取版本，没发 Release 前走 HACS 装不到 0.4.0。

## 链路 A：HACS 正式链路（推荐）

1. **推送**：`git push origin main`（本地 6 个 commit 一次推齐；push 归用户）。
2. **建 Release**（GitHub 仓页 → Releases → Draft a new release）：
   - tag：`v0.4.0`（打在 main 最新 commit 上）
   - 标题：`v0.4.0`
   - 正文可直接引用 README「更新日志」0.4.0 段。
3. **HA 侧 HACS 添加自定义仓库**：HACS → ⋮ 菜单 → 自定义仓库 → 仓库填 `https://github.com/SagisawaTsubasa/water-heater-optimizer`，类别选 **集成（Integration）**。
4. HACS 中安装 **Water Heater Optimizer** → 按提示重启 Home Assistant。
5. 已装旧版（0.3.0）的：HACS 里更新到 0.4.0 后重启 HA，随后按《条目重配指引.md》重配条目。

## 链路 B：手动安装（不发 Release 时）

1. 把本仓 `custom_components/water_heater_optimizer/` 整目录复制到 HA 配置目录 `custom_components/` 下，覆盖旧版。
2. **手动删除旧版残留文件**：覆盖复制不会删除旧目录里已砍除的文件——v0.3.0 目录里的 `services.yaml` 在 v0.4.0 已删（take_snapshot 服务随触发器体系整体移除），务必手动删掉，避免留下一份描述着不存在服务的 YAML。
3. 重启 Home Assistant。
4. 同样按《条目重配指引.md》重配条目。

## 部署后自检（一步）

重启完成后，日志（设置 → 系统 → 日志，或记录器 `custom_components.water_heater_optimizer`）应无 ERROR；条目重配完成前推荐温度实体可能显示旧值/unknown，属预期，见《条目重配指引.md》。
